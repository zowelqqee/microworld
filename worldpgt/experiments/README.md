# worldpgt/experiments — Artifact Index

This directory contains scripts and generated artifacts for the Microworld Controlled Continuation benchmark.

All commands run from the `worldmvp/` parent directory.

---

## Source Scripts

| Script | Purpose |
|--------|---------|
| `run_v1_microworld_continuation.py` | Run Microworld pipeline on `continuation_prompts_v1.csv`; writes per-row output CSV |
| `run_v1_1_microworld_continuation.py` | Alias for v1.1 run (same engine, earlier policy) |
| `run_v1_2_microworld_continuation.py` | Alias for v1.2 run (anti-cue guarded policy) |
| `summarize_v1_microworld_results.py` | Aggregate per-row CSV into sense/audit/suppress counts by difficulty type |
| `summarize_risk_coverage.py` | Compute coverage_rate, answerable_recall, precision_on_continued |
| `compare_v1_to_v1_1.py` | Row-by-row diff of v1.0 vs v1.1 outputs |
| `compare_v1_1_to_v1_2.py` | Row-by-row diff of v1.1 vs v1.2 outputs |
| `compare_continuation_outputs.py` | Compare Microworld against Fable5 baseline (24-row subset) |
| `check_realization_quality.py` | Checks surface form of emitted continuations |
| `risk_coverage_metrics.py` | Library module (imported by `summarize_risk_coverage.py`) |
| `policy_sweep.py` | Grid search over policy thresholds |

## Full Comparison Report

| File | Description |
|------|-------------|
| `full_comparison_report.json` | Structured JSON report: quality, risk/coverage, runtime, RSS, state-size comparisons |
| `full_comparison_report.md` | Human-readable Markdown version of the same report |

Generated by:
```bash
python3 -m worldpgt.benchmarks.full_comparison_report \
    --microworld-output worldpgt/experiments/microworld_continuation_v1_2_outputs.csv \
    --microworld-risk worldpgt/experiments/microworld_continuation_v1_2_risk_coverage.json \
    --gpt2-audit worldpgt/experiments/gpt2_continuation_audit_labeled.csv \
    --gpt2-summary worldpgt/experiments/gpt2_continuation_audit_summary.json \
    --runtime worldpgt/experiments/runtime_benchmark_summary.json \
    --state-size worldpgt/experiments/state_size_benchmark_summary.json \
    --rss worldpgt/experiments/rss_benchmark_summary.json \
    --json-output worldpgt/experiments/full_comparison_report.json \
    --md-output worldpgt/experiments/full_comparison_report.md
```
