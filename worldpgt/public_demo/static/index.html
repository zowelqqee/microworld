How it works

Each layer has one job. Factual support never comes from presentation code.

  1. 01

    Explicit graph

    Admitted entities and relations form a bounded local memory.

  2. 02

    Planner

    A deterministic route selects the smallest supported path.

  3. 03

    Audit gate

    Current, private, ambiguous, or missing claims stop without a guess.

  4. 04

    Renderer

    Only admitted evidence is turned into readable language.
