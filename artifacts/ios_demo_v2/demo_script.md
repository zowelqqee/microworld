# MicroWorld iOS v2 — live offline demo script

The app ships the current `worldpgt` package plus the local v2 serving graph.
The graph has 1,266 items / 990 relations, with the validated multi-evidence
subject cohorts `331 original + 46 Crossref + 12 Wikidata + 2 OpenAlex`.

Use QA mode.  Turn on Airplane Mode before the first prompt and keep it on.
Each answer is generated by the embedded CPython runtime; no response is
pre-recorded.
